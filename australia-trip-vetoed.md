# Sydney + Whitsundays — Vetoed Options

*Things we considered but decided against. If someone in the group wants to revisit, discuss here.*

---

| Option | Why Vetoed |
|--------|-----------|
| **Tahiti** | Too far from Sydney to squeeze into 10 days |
| **Cairns / Great Barrier Reef from CNS** | Inshore reef looks underwhelming from photos; requires diving for the good stuff |
| **Hamilton Island day trip** | Expensive ferry for what's basically walking around a resort you're not staying at |
| **Lord Howe Island** | Overlapping vibe with Whitsundays (both are turquoise lagoon + beach) |
| **New Zealand / South Island** | Would mean cutting Whitsundays; better saved for its own trip |
| **Tasmania** | Tight to fit in; late winter weather (12-16°C); adds more flights |
| **Uluru** | Cool but logistically heavy fly-in-fly-out detour for 2-3 days |
| **Hunter Valley wine region** | Cut to keep a buffer day before the long flight home |
| **Cockatoo Island** | Looks rudimentary — convict ruins and shipyard aren't worth the time |
| **Opera House guided tour ($45)** | Free to walk around exterior + public concourse. Don't care about history enough to pay for interior tour. |
| **Opera House backstage tour ($175)** | Same — not worth it if not into the history |
| **Bondi → Coogee guided walk ($50)** | Easy enough to DIY for free — same route, no guide needed |
| **Blue Mountains — Active/backpacker tour ($100–130)** | Not the vibe we're going for |
| **Blue Mountains — Private tour + wildlife + ferry ($250+)** | Too expensive for what it is |
